# FX-M2-005 — 大きさ上限の境界

- Source: C2 / MC-005
- Invariant: INV-005
- Test ID: M2-FX-005

## Scenario

diff 行数と chunk 数を、それぞれ独立に境界値、その内側、直上で与える。

- diff 行数: 3,200行ちょうど / 3,199行（内側） / 3,201行（直上）
- chunk 数: 8チャンクちょうど / 7チャンク（内側） / 9チャンク（直上）

## Observable expected result

- diff 行数は3,200行ちょうどおよび3,199行（境界の内側）が受理され、処理成功する。
- diff 行数3,201行（直上）は、非完了または拒否として終端する。
- chunk 数は8チャンクちょうどおよび7チャンク（境界の内側）が受理され、処理成功する。
- chunk 数9チャンク（直上）は、非完了または拒否として終端する。
- 処理時間、メモリ、生成量が入力超過に伴って無界に増えない。
