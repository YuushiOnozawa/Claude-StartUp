# FX-M2-020 — 秘密情報・権限・出力経路分離

- Source: 正本プラン「受け入れ条件（DoD）> 実行系」節 / 本レビュー指摘
- Invariant: INV-020
- Test ID: M2-FX-020

## Scenario

入力および実行環境に token 等の秘密情報が含まれる run を、正常終了・異常終了・signal 終了の各経路で実行する。一時ファイル・一時ディレクトリの作成と、正常な結果および診断・エラー出力の生成も観測対象にする。

## Observable expected result

- 秘密情報が stdout/stderr、結果、診断、artifact、ログのいずれにも残らない。
- 一時ファイル・一時ディレクトリは作成時点から所有者のみがアクセスできる制限的な権限であり、run 終了後は正常・異常・signal のいずれでも残らない。
- 正常な結果と診断・エラー出力は別の出力経路に分離され、診断が結果に混入して結果の検証を壊さない。

## Out of scope

- 実行コマンド
- JSON schema
- lock 名、post key 名、関数名
